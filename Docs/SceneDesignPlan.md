# 2DJump 场景与流程设计方案

## 概览
当前项目只有一个可游玩的关卡。本方案给出了完整的开场流程设计、关卡选择界面以及新增的多关卡蓝图，同时定义了统一的游玩目标规则，便于后续在 Unity 中逐步实现。

## 开始界面（Start Screen）
### 入口流程
1. 启动游戏后加载 `StartScreen` 场景。
2. 背景使用柔和的像素艺术图（可复用 `Arts/` 中的山景资源），中央展示游戏标题和角色静态或轻微呼吸动画。
3. 底部提供三个核心按钮：`开始游戏`、`关卡选择`、`设置`。
4. 右下角保留版本号与制作人员信息的文本区域，使用 TextMesh Pro 字体提高可读性。

### 交互逻辑
- `开始游戏`：默认载入 `LevelTutorial`，并在 GameManager 中将苹果计数、计时器重置。
- `关卡选择`：切换到关卡选择界面（可在同场景使用 Canvas 分页或加载独立 `LevelSelect` 场景）。
- `设置`：打开弹出面板，包含音量调节（滑杆直接影响 `AudioMixer`）、按键提示图，以及返回按钮。
- 支持手柄与键鼠导航：使用 Unity Input System 的 `UI Input Module`，确保按钮可用 `WASD/方向键` 与 `A/B` 操作。

### 视觉与音效
- 背景音乐：循环播放节奏轻快的片头曲，音量略低于关卡 BGM，切换到游戏场景时淡出。
- 按钮 Hover 与点击添加轻量音效，提升反馈感。

## 关卡选择界面（Level Select）
### 布局结构
- 使用网格布局显示每个关卡卡片，内容包含：关卡名称、预览缩略图、星级评价（完成度）、苹果收集进度。
- 左侧垂直导航栏可快速跳转到不同章节（如“教程”、“森林”、“洞穴”）。
- 顶部显示玩家总苹果数与最佳时间记录，直接读取 `GameManager` 的持久化数据（可通过 ScriptableObject 或存档实现）。

### 解锁逻辑
- 关卡按章节线性解锁：完成上一关并满足目标（苹果 ≥ 要求、通关时间 ≤ 上限）才可解锁下一关。
- 未解锁的卡片显示锁图标与提示需求。
- 已完成关卡可点击查看详细成绩，并提供 `重玩` 按钮。

### 技术实现提示
- 可创建 `LevelDefinition` ScriptableObject，包含场景名称、目标要求、解锁条件、缩略图等字段。关卡选择界面读取该列表动态生成卡片。
- 将选中关卡传递给 `GameManager` 后调用 `SceneManager.LoadScene` 切换。

## 新增场景蓝图
### LevelTutorial（教学关）
- **目标**：引导玩家掌握移动、跳跃、拾取苹果与避开陷阱。
- **流程**：
  1. 起始平台展示提示板，使用 `Trigger2D` 触发 UI 气泡。
  2. 低矮障碍训练基本跳跃；脚下放置可见的 `DeathArea` 以演示跌落惩罚。
  3. 最后设置 5 个苹果，收集完即可触发传送门（使用 `LevelPass`）。
- **教学提示**：分阶段触发 `UnityEvent`，显示按键说明与小动画。

### LevelForest（森林关）
- **主题**：郁郁葱葱的森林背景，加入摇摆平台与飞行敌人。
- **元素**：
  - `MovingPlatform` 脚本控制水平/垂直移动（可新建或扩展现有脚本）。
  - 树藤绳索作为一次性跳板，使用 `SpringJoint2D` 制造弹性效果。
  - 新增收集物 `GoldenApple`，价值 3 个普通苹果。
- **目标**：在 3 分钟内收集至少 25 个苹果，并到达终点旗帜。
- **隐藏收集**：设置支线区域奖励额外苹果或时间减免。

### LevelCavern（洞穴关）
- **主题**：幽暗洞穴，强调垂直探索与陷阱。
- **元素**：
  - 滴水陷阱：使用 `Spike` 逻辑但改为周期性落石，需通过 `Animator` 控制。
  - 暗区：添加局部光源，限制玩家视野，突出探索感。
  - 可破坏墙壁：玩家踩踏开关后触发 `DestroyGameObject`，打开新路径。
- **目标**：收集隐藏在分支路线的 3 枚钥匙（可使用 `Apple` 脚本改写），到达最底部的出口。
- **复活点**：设置多个 `Checkpoint`，通过 `GameManager` 记录玩家重生位置。

### LevelSkyRuins（天空遗迹关）
- **主题**：浮空遗迹与强风机制，利用 `WindZone2D`（自定义脚本）推力影响跳跃。
- **元素**：
  - 连续的浮空平台、风扇装置、消失平台（启用/关闭 `SpriteRenderer` 与碰撞体）。
  - 收集 30 个苹果解锁终端祭坛，站立 5 秒触发胜利动画。
- **挑战**：加入计时奖励；在 2 分钟内完成可获得额外星级。

## 游玩目标与规则
1. **基础目标**：每关至少收集指定数量的苹果才能解锁终点传送门。若苹果不足，GameManager 显示提示文本并阻止 `LevelPass` 触发。
2. **计时系统**：沿用 `LevelTime` 计时脚本，为每关设定金/银/铜三档时间目标，记录最佳成绩并展示在关卡选择界面。
3. **生命与复活**：玩家默认 3 条生命。跌落 `DeathArea`、碰到 `Spike` 或敌人时生命 -1，归零即回到关卡选择界面。每次死亡时返回最近的 `Checkpoint`。
4. **奖励机制**：额外收集苹果或完成隐藏挑战可解锁角色装扮/音轨等外观奖励，记录在持久化存档中。
5. **难度曲线**：
   - 教学关侧重基础操作与宽松时间。
   - 森林关引入移动平台与多路径。
   - 洞穴关加入视野限制与机关解谜。
   - 天空遗迹关强调精准跳跃与风力控制，作为进阶挑战。

## 实施建议
- 按场景逐步创建 `*.unity` 文件，并在 `Scenes` 目录中保持命名一致。
- 使用 Prefab 管理关卡中的常用元素（苹果、陷阱、检查点），减少重复配置。
- 在 `ScriptableObject` 里维护关卡元数据，方便关卡选择界面读取与扩展。
- 每次新增资源后更新版本控制，确保团队可追踪场景迭代。

该方案可作为团队后续实现与美术制作的蓝图，同时兼顾了关卡节奏、解锁路径与重玩价值。
